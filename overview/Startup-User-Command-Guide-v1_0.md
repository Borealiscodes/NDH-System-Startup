## ⭐ 2 — Command Philosophy

NDH commands must be:

- **non‑activating**  
- **non‑recursive**  
- **altitude‑aware**  
- **sequencing‑safe**  
- **collapse‑resistant**  

Commands do **not** manipulate NDH internals.  
They manipulate **navigation surfaces**.

---

## ⭐ 3 — Core Command Set

### **A. Sequencing Commands**

- **Next**  
  Advance to the next artifact in the corridor.  
  Equivalent to stepping forward along the temporal spine.

- **Hold**  
  Freeze the corridor.  
  Prevents accidental forward progression.

- **Pause**  
  Same as Hold, but softer pacing.

- **Stop sequencing**  
  Hard stop.  
  Prevents any further altitude movement.

---

### **B. Altitude Commands**

- **Return to A0**  
  Re‑center at the origin altitude.  
  Does *not* reboot NDH (protected by Loop Closure Manifest).

- **Ascend to A10 / A11 / A12**  
  Move to a specific altitude’s expressive surface.  
  Does not activate membranes.

- **Descend**  
  Move downward in the altitude corridor.

---

### **C. Membrane Navigation Commands**

- **Open membrane: X**  
  View the expressive surface for a membrane (e.g., Anchor, Closure).

- **List membranes**  
  Show all membranes in the current corridor.

- **Show corridor**  
  Display the altitude‑mapped temporal corridor.

---

### **D. Stability Commands**

- **Stabilize altitude**  
  Lock the current altitude to prevent drift.

- **Lock corridor**  
  Prevent any forward or backward movement.

- **Check invariants**  
  Display the Lean‑verified invariants bound to the corridor.

---

### **E. Expressive Commands**

- **Explain X**  
  Provide a human‑readable explanation of any membrane or artifact.

- **Summarize corridor**  
  Provide a high‑level overview of the entire startup ecosystem.

- **Show index**  
  Display the Repository Index Map.

## ⭐ 5 — Safety Rules

### **Rule 1 — No Activation**  
Commands must not activate NDH‑CORE or expressive engines.

### **Rule 2 — No Recursive Sequencing**  
Commands must not trigger nested “Next” cycles.

### **Rule 3 — No Altitude Inversion**  
Commands must not jump from A12 directly to A10 without passing A11.

### **Rule 4 — No Foreign‑Membrane Drift**  
Commands must not modify Lean‑verified invariants.

### **Rule 5 — No Governance Activation**  
Commands must not activate NDH‑COORDINATION or Verdant Deep.
